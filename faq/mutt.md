## Configuring and using mutt

[Mutt](https://www.mutt.org) is a free and open source text based mail user agent (email client) suitable for use in your terminal.

Open the course email list by running the `mutt` command within your class container.

It is already configured to use your course credentials to access the course email list as you.

Before the relevant submission deadline for each component of each assignment, you will see no messages in your inbox related to it, even your own submission(s).
All email is released at most once a day in a batch after the corresponding due date passes. As such, interactive discussions are not possible over
email, and you should use the course Matrix for them instead.

In `mutt`, you will see a list of email threads.

Press:

* `enter` to view which message you have highlighted

* `q` while viewing a message to exit back to the main screen.

* `space` to scroll to the next page within the email.

* `q` or `ctrl+c` to exit `mutt`.

* `r` while viewing a message to draft a reply.

You can configure your own email client (e.g. thunderbird) to use your course account
if you wish, but if you do so, the instructors will not be able to help troubleshoot
any issues that might occur, so you acknowledge that any problems that result from
using a different email client are your own responsibility to resolve and do not form
viable grounds for excusing any failure to complete required course submissions.
